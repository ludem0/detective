# Detective — сайт для командной детективной игры

Веб-движок для проведения детективной игры в стиле Saint Twins Detective вживую: несколько команд расследуют одно дело, «ездят» по адресам города, получают показания и улики, заполняют бланк ответов. Ведущий управляет игрой с отдельного пульта.

Сейчас в репозитории лежит дело №24 «Зачарованный всадник».

> ⚠️ **Спойлер.** `case/case24.yaml` содержит разгадку и ответы на все адреса. Если собираетесь играть в это дело, не открывайте папку `case/`.
>
> Материалы дела (тексты, карты, газеты, приложения, портреты в `case/`) взяты из оригинальной игры и принадлежат её авторам. Код движка (`app/`, `tests/`, `tools/`) написан с нуля.

## Что умеет

**Для команд**
- Вход по логину и паролю команды; одна учётка работает с нескольких устройств одновременно, поездки и бланк общие.
- Ввод адреса (`СЗ-37/504`, `ц 12`, `Ю-38/криминалист`): регистр, пробелы и дефисы не важны.
- Журнал поездок с показаниями, портретами собеседников и приложениями (PDF и сканы с просмотром).
- Материалы дела: обращение, карты районов, адресная книга, газеты, справочник.
- Ордер и обыск: `адрес/ордер` → через N секунд в журнал приходит «Ордер готов» → `адрес/обыск`.
- Триггеры: сообщения, которые приходят сами, когда команда побывала в нужных местах.
- Бланк ответов, который сохраняется на лету и отправляется один раз.

**Для ведущего** (`/admin`)
- Создание команд, генерация паролей, печать карточек.
- Таймер игры: старт, пауза, +10 минут.
- Подсказки (по времени или вручную) и сообщения всем командам.
- Просмотр экрана любой команды в режиме «только чтение».
- Оценка ответов рядом с эталоном, подсчёт гонорара: `$20 × Баллы² / √Поездки`.
- Публикация итогов и разгадки командам.
- Сброс прогресса без удаления команд.

## Стек

- **Backend:** Python 3.11, FastAPI, SQLite (stdlib `sqlite3`), PyYAML
- **Frontend:** чистые HTML/CSS/JS без сборки и фреймворков, опрос `/api/state`
- **Деплой:** Docker Compose: приложение + nginx
- **Тесты:** pytest + httpx (движок и API)

## Структура

```
app/
  main.py       FastAPI-приложение: эндпоинты команд и ведущего, раздача файлов
  game.py       игровая логика: поездки, ордера, триггеры, таймер, подсчёт
  casefile.py   загрузка дела из YAML, разбор и нормализация адресов
  db.py         схема SQLite и доступ к данным
  auth.py       пароли (scrypt), сессии, лимит попыток входа
  static/       интерфейс команды (index.html, app.js) и пульт ведущего (admin.*)
case/
  case24.yaml   сценарий дела (СПОЙЛЕР)
  addressbook.json, files/   адресная книга, карты, приложения, портреты
tests/          тесты движка и API
tools/
  build_assets.py   разовая сборка файлов дела из исходных сканов
```

## Как устроено дело

Всё дело описывается одним YAML-файлом. Движок про конкретное дело ничего не знает: другое дело подключается заменой `case/`.

| Раздел | Что в нём |
|---|---|
| `brief`, `contacts`, `materials` | вступление и стартовые материалы |
| `districts` | коды районов и их карты |
| `entries` | ответы по адресам; `requires` — адреса, без которых ответ пустой |
| `searches` | результаты обысков, приходят через `order_delay_sec` после ордера |
| `triggers` | сообщения, которые приходят сами после посещения набора адресов |
| `hints` | подсказки: по времени или вручную |
| `questions`, `rubric`, `debrief` | вопросы бланка, эталон для ведущего, разгадка |

## Запуск локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt        # Linux/macOS: .venv/bin/pip
.venv/Scripts/python -m pytest -q tests
ADMIN_PASSWORD=local-admin-pw .venv/Scripts/python -m uvicorn app.main:build_app --factory --port 8765
```

Откройте http://localhost:8765/admin, войдите логином `admin` и паролем из `ADMIN_PASSWORD`, создайте команду и войдите под ней на http://localhost:8765 в другом браузере.

## Запуск в Docker

```bash
git clone https://github.com/ludem0/detective.git && cd detective
cp .env.example .env      # задать ADMIN_PASSWORD (от 8 символов)
bash deploy.sh            # docker compose up -d --build
```

Сайт откроется на порту **8083** (меняется в `docker-compose.yml`). База лежит в `./data/game.db`, при пересборке она сохраняется.

Приложение работает в один воркер: блокировка SQLite и лимитер входа хранятся в памяти процесса.

## Как провести игру

1. Войдите на `/admin` как `admin`.
2. **Команды** → добавьте каждую команду. Пароль показывается один раз: перепишите его или нажмите «Печать».
3. Команды входят со своих устройств; до старта они видят экран ожидания.
4. Зачитайте обращение и нажмите **Старт**. Таймер — 2 часа.
5. Первая подсказка выходит сама на 30-й минуте, остальные — кнопкой «Выпустить».
6. Когда время выйдет, поездки закрываются и команды отправляют бланк. Если бланк отправили по ошибке, нажмите «Вернуть бланк».
7. Выставьте баллы по вопросам. Эталон показан рядом с ответом команды.
8. Отметьте «Показать командам итоги» и «Показать разгадку».

Перед игрой прогоните тестовую команду, затем нажмите «Сбросить игру».

## Механика

- Адрес = район + номер дома; дробь — квартира, кабинет или номер (`СЗ-37/504`).
- Каждая новая поездка добавляет +1 к счётчику, даже если по адресу ничего нет. Повтор той же поездки бесплатен.
- `адрес/криминалист` считается отдельной поездкой.
- `адрес/ордер` — поездка. После неё в журнал бесплатно приходит «Ордер готов», а `адрес/обыск` — вторая поездка, которая даёт результат. Обыск до готовности ордера даёт подсказку и не считается поездкой.
- Приложения видит только та команда, которая их получила.
