# Detective — дело №24 «Зачарованный всадник»

Сайт для командной игры в стиле Saint Twins Detective: команды входят под своими логинами, «ездят» по адресам Сейнт-Твинс, получают показания и приложения, заполняют бланк ответов. Ведущий управляет таймером, подсказками, оценкой и итогами.

**Внимание: `case/` содержит разгадку и ответы на все адреса.** Не показывайте репозиторий игрокам.

## Как провести игру

1. Откройте `http://<сервер>:8083`, войдите логином `admin` и паролем ведущего (`ADMIN_PASSWORD` из `.env`). Откроется пульт.
2. **Команды** → добавьте каждую команду. Пароль показывается один раз: перепишите его или нажмите «Печать», чтобы раздать карточки.
3. Команды входят со своих устройств (одна учётка на команду, можно с нескольких телефонов и ноутбуков: поездки и бланк общие). До старта они видят экран ожидания.
4. Зачитайте обращение (оно же во вкладке «Материалы дела» у команд) и нажмите **Старт**. Таймер 2 часа, его можно продлить (+10 мин) или остановить.
5. Подсказка из оригинальной игры выйдет сама на 30-й минуте. Ещё две — по кнопке «Выпустить», если команды застряли. Любое сообщение всем — полем «Сообщение всем командам».
6. Когда время выйдет, поездки закроются. Команды отправляют бланк. Если кто-то отправил по ошибке — «Вернуть бланк».
7. Откройте каждую команду и выставьте баллы по вопросам: рядом с ответом команды показан эталон. Гонорар = $20 × Баллы² / √Поездки, при равенстве выше тот, у кого меньше поездок.
8. Поставьте галочки «Показать командам итоги» и «Показать разгадку» — у команд появится вкладка «Итоги».

Перед реальной игрой сделайте тестовую команду, пройдите пару адресов, затем «Удалить» её или «Сбросить игру» (команды и пароли сохраняются, прогресс стирается).

## Механика

- Адрес = район + номер дома, дробь — квартира, кабинет, номер в гостинице (`СЗ-37/504`). Регистр, пробелы и дефисы не важны.
- Новая поездка = +1 к счётчику, даже если по адресу ничего нет. Повтор того же ответа бесплатен.
- `адрес/криминалист` — отдельная поездка. `адрес/ордер` — поездка; через «Ордер оформляется, сек» (по умолчанию 300) в журнал бесплатно приходит «Ордер готов», и `адрес/обыск` — вторая поездка с результатом. Обыск до готовности ордера — подсказка, без поездки.
- Триггеры: звонок из театра приходит сам через минуту после визита в театр и гостиницу.
- Приложения открываются только той команде, которая их получила.

## Разработка

```
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest -q tests
ADMIN_PASSWORD=local-admin-pw .venv/Scripts/python -m uvicorn app.main:build_app --factory --port 8765
```

Сценарий дела — `case/case24.yaml` (тексты ответов, приложения, триггеры, подсказки, эталон). Файлы дела в `case/files` собраны из проекта Detective скриптом `tools/build_assets.py` (нужны Pillow и pymupdf; на сервере не запускается).

## Деплой

Сервер: compose-nginx на порту **8083**, база — `./data/game.db` (bind-mount, в git не идёт).

```
git clone <repo> ~/detective && cd ~/detective
cp .env.example .env   # задать ADMIN_PASSWORD
bash deploy.sh
```

Обновление: `cd ~/detective && git pull && bash deploy.sh`. Данные игры при пересборке сохраняются.
